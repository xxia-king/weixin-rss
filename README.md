# 微信公众号 RSS 索引

这份清单按公众号整理文章，目前收录「律鹿」。每条记录提供标题、发布日期和微信原文链接。

[下载统一订阅目录（OPML）](https://github.com/xxia-king/weixin-rss/releases/latest/download/weixin-rss.opml)，在阅读器中选择「导入 OPML」即可。

![Star 数](https://img.shields.io/github/stars/xxia-king/weixin-rss) ![历版订阅目录累计下载次数](https://img.shields.io/github/downloads/xxia-king/weixin-rss/total?label=OPML%20downloads)

如果这份清单对你有帮助，欢迎给仓库点个 Star。发现错链或想推荐值得收录的公众号，也欢迎提交 Issue。
