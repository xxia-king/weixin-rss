# 微信公众号 RSS 索引

每个公众号有一份可供阅读器订阅的 RSS。当前收录「律鹿」，文件为 `feeds/lvlu.xml`。每条记录提供文章标题、发布日期和微信原文链接，点击链接即可前往公众号阅读。

## 在 Folo 中订阅

复制下面的完整地址，粘贴到 Folo 的添加订阅入口即可。后续更新沿用同一地址。

```text
https://xxia-king.github.io/weixin-rss/feeds/lvlu.xml
```
